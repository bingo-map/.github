# BinGo Map — Clean & Gourmet
일본 여행 중 쓰레기통과 주변 테이크아웃 맛집을 지도에서 함께 찾아보세요.
오사카 도톤보리에서 시작한 팀 프로젝트입니다.
## 주요 기능
- 지도에서 쓰레기통 위치 확인
- 주변 테이크아웃 맛집 탐색
- 리뷰와 커뮤니티 기능
- 회원 계정 및 마이페이지
## 기술
Java 17 · Spring Boot · Gradle · Oracle Database
HTML · CSS · JavaScript · Leaflet · OpenStreetMap Overpass API
